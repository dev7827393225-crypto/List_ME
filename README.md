Shopping List App

A simple and modern Android Shopping List application built using Jetpack Compose and Material 3.
The app helps users manage their shopping items efficiently by allowing them to add, edit, and delete items along with their quantities.

✨ Features

➕ Add shopping items with quantity

✏️ Edit existing items

🗑️ Delete items from the list

📦 Persistent local storage using Room Database

🎨 Modern UI using Jetpack Compose & Material 3

🧠 Clean architecture with MVVM pattern

🛠️ Tech Stack

Language: Kotlin

UI: Jetpack Compose, Material 3

Architecture: MVVM (Model–View–ViewModel)

Database: Room

State Management: ViewModel & LiveData

📱 Screens & UI

Material 3 TopAppBar

Floating Action Button for quick item addition

Clean and minimal user interface

Responsive layout using Compose
